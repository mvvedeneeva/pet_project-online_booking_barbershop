# Пет проект | Система онлайн-записи для сети барбершопов
Учебный проект, направленный на разработку системы онлайн-записи для сети барбершопов. В репозиторий включены результаты без исходных условий или контекста для сохранения конфиденциальности информации.
 
Результаты работы разбиты по темам и кратко описаны, прикреплена ссылка на соответствующий документ. Где необходимо, подкреплены 2 формата: PDF и исходный редактируемый (xlsx, docx). Таким образом, все документы можно просмотреть, не скачивая репозиторий. 

Цель проекта — создать систему онлайн-записи для сети барбершопов, чтобы автоматизировать рутинные процессы, уменьшить ручной труд, расширить клиентскую базу.

## Что сделано 
Все документы разделены на 3 группы, иллюстрирующие этапы работы бизнес- и системного аналитика.
