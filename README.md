# pet-project_barbershop
Учебный проект, направленный на разработку системы онлайн-записи для сети барбершопов. В репозиторий включены результаты без исходных условий или контекста для сохранения конфиденциальности информации.

## Навигация 
В документе кратко представлены результаты работы, с ссылкой на соответствующий документ. Документы предоставлены в двух форматах, где необходимо: PDF и исходный редактируемый (xlsx, docx). Таким образом, все документы можно просмотреть, не скачивая репозиторий. 

### Изучение предметной области
- Составила реестр из 9 источников информации (infosources)
- Составила глоссарий, состоящий из 20 терминов (glossary)
- Выявила 10 ключевых стейкхолдеров, их интересы, потребности (stakeholders), а также проблемы AS IS и решение этих проблем TO BE (problems ASIS-TOBE)
- Построила контекстную диаграмму (context)
- Составила словарь данных из 10 терминов (data dictionary)
- Построила диаграмму и таблицу состояний (state diagram & state table), а также Swimlane-диаграмму («Плавательные дорожки») Выполнения услуги

### Требования и пользовательские сценарии
- Проверила выбранные сущности по CRUD
- Дополнила Swimlane-диаграмму («Плавательные дорожки») артефактами 
- Формализировала Use Cases и User Stories

### Моделирование процессов
- Описала 10 объектов и составила диаграмму классов
- Построила диаграмму потоков данных (DFD)
- Выделила основные бизнес-процессы и описала в BPMN
